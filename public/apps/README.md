# App screenshots

Drop hero screenshots for each app here, named to match the slug in `lib/apps.ts`:

```
public/apps/rca-flow/hero.png
public/apps/m32-cnc-analyser/hero.png
public/apps/ship-it/hero.png
public/apps/hydraulics-calculator/hero.png
public/apps/prd-builder/hero.png
public/apps/career-conversation/hero.png
```

Recommended size: 1600×1000 (16:10). PNG or WebP.

Videos: drop MP4s alongside (`hero.mp4`) and set `videoUrl` in `lib/apps.ts`.
